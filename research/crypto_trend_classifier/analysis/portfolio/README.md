# المحفظة (Portfolio)

إدارة المحفظة الحقيقية وإدارة الخسارة: الوضع الحالي، والمخاطرة في كل عملة، ومقارنات تاريخية، والخطط والقرارات.

- **`YYYY-MM-DD_portfolio_review.md`:** مراجعة كاملة، فيها الوضع، والمخاطرة، والسيناريوهات، والخطة.
- **`YYYY-MM-DD_holdings.json`:** الكميات والتكلفة لكل عملة (`{"COIN": {"qty", "cost"}}`). ده المدخل لـ `python -m tc.portfolio`.
- **`YYYY-MM-DD_risk_snapshot.json`:** ناتج `tc.portfolio`، وفيه لكل عملة: الترند، والخطوط، والتذبذب، وحساسيتها لـ BTC (beta)، ونتيجة سيناريو الهبوط.
- **المقارنة التاريخية:** `python -m tc.portfolio_backtest`.

**القواعد:**
- **ما تحطش هنا** كشوف الحساب، ولا الاسم، ولا الإيميل، ولا رقم الحساب. الأرقام بس.
- **كل مراجعة جديدة ليها ملف بتاريخها،** والقديم يفضل زي ما هو، علشان نقدر نقارن القرارات بالنتايج بعدين.
