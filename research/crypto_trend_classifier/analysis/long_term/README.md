# المدى الطويل (من 6 شهور لسنة)

الدورات، والهيكل الأسبوعي، والمتوسطات الطويلة، والتدفقات المؤسسية على مدى شهور. السؤال هنا: إحنا فين في الدورة؟

## الفولدرات
- [`macro/`](macro/): الكلي
- [`positioning_flows/`](positioning_flows/): التمركزي والتدفقي

- **كل عملة ليها فولدر باسمها** (`BTC/`، `LINK/`، …). بيتعمل لما نحلل العملة دي لوحدها.
- فولدر `macro/` و`positioning_flows/` للسوق كله.
- اسم الملف: `YYYY-MM-DD_<الموضوع>.md`، والتاريخ هو تاريخ آخر بيانات اتبنى عليها التحليل.
- الفهرس الكامل للمدى ده: [INDEX.md](INDEX.md).

كل التحاليل هنا وصفية، مش توقع، ومش نصيحة مالية.
